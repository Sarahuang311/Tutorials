# J381M Tutorials

Welcome to the tutorial repository for **J381M**. This repository contains all the weekly handouts, code snippets, and exercise files needed for the course.

## 📁 Repository Structure

The materials are organized chronologically by week. For most weeks, you will find both a standard folder containing the raw files and a `.zip` archive for easy downloading. 

## 🚀 How to Use This Repository

**Option 1: Download specific weeks (Recommended for beginners)**
1. Navigate to the `.zip` file for the week you need (e.g., `W1.zip`).
2. Click on the file, then click the **Download** button (usually represented by a downward arrow icon on the right side).
3. Unzip the file on your local computer to access the materials.

**Option 2: Clone the entire repository (For advanced users)**
If you are familiar with Git and want to keep all files updated on your local machine, you can clone the repository:

```bash
git clone [https://github.com/Sarahuang311/Tutorials.git](https://github.com/Sarahuang311/Tutorials.git)
